# 2D Game UI Improvement Prompt

Turn the app into a polished 2D game-style lo-fi room player.

The room must read clearly at a glance:

- The hanging lamp/light is visibly a light source.
- The cat is visually recognizable as a cat.
- The window/rain, turntable/vinyl, radio/drums, coffee/cafe, and keyboard/preset controls are distinct.
- Every interactive item has a generous click target.
- Hover and keyboard focus make the active object obvious.
- The room status, play button, clock, and object labels do not overlap the artwork.
- The audio and preset features continue to work without changing the core music behavior.

Implementation rule: improve the existing lightweight canvas game scene and DOM controls without adding a new dependency.
